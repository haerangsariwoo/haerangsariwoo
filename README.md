# 해랑사리우 웹앱

한성대학교 봉사동아리 **해랑사리우** 전용 웹앱 프로젝트.

## 문서
- [해랑사리우 웹앱 브리핑](해랑사리우_브리핑.md) — 와이어프레임/개발용 요구사항 정리 (전체 IA + 화면별 상세)

## 개요
- **메인 앱** (부원 전용): 홈 · 활동 · 봉사 모집 · 커뮤니티 · 마이 + 운영진 관리자
- **모집 앱** (외부 공개): 동아리 소개 + 신입 부원 모집 (지원 → 1차 → 면접 → 최종)

## 기술 스택
- 프론트: Next.js + Vercel
- 백엔드: Supabase + Go
- UI: shadcn (Tailwind 미사용)
