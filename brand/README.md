# 브랜드 원본

앱에 들어가는 로고·아이콘의 **원본 파일**입니다. (1024×1024)

| 파일 | 배경 | 용도 |
|---|---|---|
| `logo.png` | 투명 | 앱 내 로고 (헤더·히어로·사이드바) |
| `icon-main.png` | 하늘색 | 메인 회원앱 아이콘 |
| `icon-recruit.png` | 네이비 | 모집앱 아이콘 |

## 수정했을 때
원본을 바꾼 뒤 아래를 실행하면 각 앱의 파생 이미지가 다시 생성됩니다.

```bash
cd apps/main && node ../../scripts/gen-icons.js
```
