| 앱 | 경로 | 포트 | 설명 |
|---|---|---|---|
| 메인 회원 웹앱 | `apps/main` | 3000 | 부원 전용. 홈·활동·봉사모집·커뮤니티·마이 + 운영진 관리자 |
| 신입모집 웹앱 | `apps/recruit` | 3001 | 외부 공개 창구. 소개·지원·결과 확인 + 모집 관리자 |

## 처음 실행하기

### 0. 준비물
**Node.js 20 이상** — 없으면 https://nodejs.org 에서 LTS 버전 설치
```bash
node -v    # v20 이상 나오면 OK
```

### 1. 코드 받기
```bash
git clone https://github.com/haerangsariwoo/haerang.git
cd haerang
```
> 이미 받아놨으면 `git pull` 로 최신화

### 2. 메인 앱 실행
```bash
cd apps/main
npm install
npm run dev
```
→ 브라우저에서 **http://localhost:3000**

### 3. 모집 앱 실행 (새 터미널 창에서)
```bash
cd apps/recruit
npm install
npm run dev
```
→ 브라우저에서 **http://localhost:3001**

> 두 앱은 포트가 달라서 **동시에 켜둘 수 있습니다.**
> 끌 때는 터미널에서 `Ctrl + C`

---

## 📱 휴대폰에서 보기

모바일 앱이라 **폰으로 보는 게 가장 정확합니다.**

1. PC와 폰을 **같은 와이파이**에 연결
2. `npm run dev` 실행하면 터미널에 이렇게 뜹니다
   ```
   - Local:    http://localhost:3000
   - Network:  http://192.168.0.10:3000   ← 이 주소
   ```
3. 폰 브라우저에 **Network 주소**를 입력

> 안 열리면 PC 방화벽에서 Node.js 허용 여부를 확인해 주세요.

## 둘러볼 화면

### 메인 회원 앱 (localhost:3000)
| 화면 | 경로 | 비고 |
|---|---|---|
| 로그인 | `/` | 아무 값이나 넣고 로그인 (인증 미연동) |
| 홈 | `/home` | 다음 활동·학기 현황·모집 봉사·공지/앨범·내 조 |
| 활동 | `/activities` | 개강파티·MT·친목 등 **동아리 행사** |
| 봉사 모집 | `/volunteer` | 봉사 신청 (내부 / 1365 · VMS 구분) |
| 커뮤니티 | `/community` | 공지 · 앨범 |
| 마이 | `/my` | 봉사시간·배지·활동기록 |
| **운영진 관리자** | `/admin` | 헤더 **☰ → 관리자 페이지** 로 진입 (데스크톱 권장) |

### 모집 앱 (localhost:3001)
| 화면 | 경로 |
|---|---|
| 공개 랜딩 | `/` |
| 지원하기 | `/apply` → `/apply/form` |
| 지원 현황·결과 | `/apply/status` — 상단 버튼으로 제출완료 / 1차 / 최종 화면 전환 |
| **모집 관리자** | `/admin` (데스크톱 권장) |

## ⚠️ 현재 상태 (테스트 전 참고)

- **데이터는 전부 예시(목업)** 입니다. 저장·수정 버튼은 아직 동작하지 않습니다.
- **로그인 인증 미연동** — 아무 값이나 넣으면 통과합니다.
- 관리자 화면은 **데스크톱 기준**으로 만들었습니다. 폰에서는 표가 좁게 보입니다.
- 봉사시간·출석은 **운영진이 수동 승인**하는 방식입니다. (QR 없음)

## 피드백 주실 때
화면 이름 + 스크린샷을 함께 주시면 반영이 빠릅니다.
예) "봉사 상세 화면 — 신청 버튼이 잘 안 보여요"
